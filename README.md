# Le Bébé

A very serious adventure about a fiddler crab in a beret who needs everyone to know he is l'homme.

## Controls
| Button | Keyboard | Gamepad | What it does |
|---|---|---|---|
| Move | Arrows or WASD | D-pad or left stick | Walk |
| A | Space, Enter, or E | A | Talk, look, pick up, use items |
| B | J or Z | B | Swing the baguette |
| X | K or X (hold) | X | Raise the croissant shield |
| Menu | Tab or I | Start or Y | Open the items sidebar |
| Mute | M | | Sound on or off |

Phones and tablets get on-screen buttons automatically.

## Files
- `index.html` loads everything
- `js/art.js` sprites (drawn as text grids) and tile art
- `js/maps.js` the maps, one character per tile
- `js/engine.js` movement, dialogue, cutscenes, input, sound effects
- `js/music.js` the music engine and all the songs (written as text)
- `js/combat.js` swinging, blocking, hearts, enemies, pickups, items sidebar
- `js/world.js` the story: characters, clues, cutscenes, chapter screens

No build step, no installs. Plain HTML and JavaScript.
