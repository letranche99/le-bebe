# Le Bébé

A very serious adventure about a fiddler crab in a beret who needs everyone to know he is l'homme.

## Controls
- Move: arrow keys or WASD
- Talk / look / confirm: Space, Enter, E, or Z
- Mute: M
- Phones and tablets get on-screen buttons automatically

## Files
- `index.html` loads everything
- `js/art.js` sprites (drawn as text grids) and tile art
- `js/maps.js` the maps, one character per tile
- `js/engine.js` movement, dialogue, cutscenes, sound
- `js/world.js` the story: characters, clues, cutscenes, chapter screens

No build step, no installs. Plain HTML and JavaScript.
